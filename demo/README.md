# Public synthetic workspace

This directory is safe to commit. All 40 SKU series, product labels, sales histories,
stock, lead times, receipts and outlier candidates are generated by `scripts/build_demo.py`.
IEK and SystemElectric are supplier labels only. No partner workbooks, transactions,
product identifiers, real candidate records or private processed artifacts are copied here.

The bundle includes only recommendation rows, product names, small synthetic candidate
records and the saved five-case evidence. Forecasts and orders are calculated with the
existing core. Case A/D remain PARTIAL: category/coefficient applicability and customer
grouping are unresolved. Synthetic evidence is not a claim about real business accuracy.

The app automatically uses this directory when no private completed runs exist.
To preview it explicitly, set `VECTOR_PROCESSED_ROOT=demo` before starting Streamlit.
No data generation, model training or external API call happens at cloud startup.

Regenerate after implementation changes using `python scripts/build_demo.py`.
This runs the small synthetic case checks and a UI review flow, not the full test suite.
The report checks source hashes (with portable LF normalization) and artifact hashes.
Keep `.gitattributes`: JSON/JSONL byte hashes must survive Windows/Linux checkouts.
